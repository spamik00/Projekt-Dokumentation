# Projekt einrichten

1. Klone das Repository:

   ```bash
   git clone https://github.com/spamik00/Projekt-Dokumentation.git
   ```

2. Wechsle in den Projektordner:

   ```bash
   cd Projekt-Dokumentation
   ```

3. Installiere die Abhängigkeiten:

   ```bash
   npm install
   ```
